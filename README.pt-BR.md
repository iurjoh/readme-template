## Demo e execução local

Este repositório é um modelo de documentação, não um aplicativo. Não há aplicativo para executar.

Ao adaptar o modelo: coloque no topo uma seção Demo com um único badge clicável. Não repita o link da demo em outros trechos. Use-o com a URL de produção verificada, se houver deploy. Não exija terminal para acessar uma demo hospedada. Se não houver deploy, explique como instalar, iniciar e abrir o projeto localmente. Não invente uma URL nem apresente previews antigos como produção. Declare limitações atuais da demo.

## Estrutura e uso

README.md contém orientação/exemplos de funcionalidades, testes, deploy e créditos; media/ guarda imagens de apoio. Raiz revisada sem código de aplicação. Preserve exemplo, substitua cada afirmação por evidência do projeto real e separe testes concluídos de planejados. Não invente user stories, deploy, histórico ou direitos de licença para preencher headings.

## Design, testes e capturas

Estrutura do documento é o resultado. Imagens existentes ilustram aula upstream, não novas capturas datadas. Nenhum runtime/suíte executado. Ao adaptar, verifique origem/links de imagens, render desktop/mobile e datas. Capturas novas em docs/assets/ só após captura real, sem dados privados.
